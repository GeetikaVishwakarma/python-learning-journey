# Practice Questions – Sets

## Beginner

1. Create a set of five fruits.
2. Add a new fruit using `add()`.
3. Remove a fruit using `remove()`.
4. Print the length of the set.

---

## Intermediate

Create two sets:

```python
A = {1,2,3,4,5}
B = {4,5,6,7,8}
```

Perform:

- Union
- Intersection
- Difference
- Symmetric Difference

---

## Membership

1. Check whether a value exists in a set using the `in` operator.
2. Check whether a value does not exist using `not in`.

---

## Challenge

Given the following list:

```python
numbers = [1,2,2,3,4,4,5,5,6]
```

Convert it into a set and display only the unique values.

## Bonus Challenge

Create two sets representing students enrolled in:

- Python Course
- Java Course

Find:

- Students enrolled in both courses.
- Students enrolled only in Python.
- Students enrolled only in Java.
