# Practice Questions – Tuples

## Beginner

1. Create a tuple of five fruits.
2. Print the first and last element.
3. Find the length of the tuple.
4. Access the third element.

---

## Intermediate

1. Create a tuple of student marks.
2. Count how many times a number appears using `count()`.
3. Find the index of a specific value using `index()`.
4. Print all elements using a `for` loop.

---

## Tuple Operations

1. Concatenate two tuples.
2. Repeat a tuple three times.
3. Check whether a value exists using the `in` operator.

---

## Challenge

Create a tuple containing:

- Name
- Age
- Branch
- College

Print each element separately using indexing.

Example:

```
Name    : Riya
Age     : 21
Branch  : CS
College : ABC
```
