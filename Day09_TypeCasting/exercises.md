# Practice Questions – Type Casting

## Beginner

1. Convert the string `"50"` into an integer.
2. Convert the integer `100` into a float.
3. Convert the float `75.8` into an integer.
4. Convert the integer `200` into a string.

## Intermediate

1. Convert the string `"Python"` into a list.
2. Convert the list `[1,2,3]` into a tuple.
3. Convert the list `[1,2,2,3,3]` into a set.
4. Check the data type after every conversion.

## Challenge

Create variables of different data types and convert them into other compatible data types.

Print:

- Original Value
- Original Data Type
- Converted Value
- Converted Data Type

Example:

```
Original Value : "100"
Original Type  : <class 'str'>

Converted Value : 100
Converted Type  : <class 'int'>
```
