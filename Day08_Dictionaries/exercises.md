# Practice Questions – Dictionaries

## Beginner

1. Create a dictionary containing:
   - Name
   - Age
   - City

2. Print all values.

3. Access the value of `"name"`.

---

## Intermediate

1. Add a new key `"college"`.

2. Update the `"age"` value.

3. Remove the `"city"` key.

4. Print all keys using `keys()`.

5. Print all values using `values()`.

---

## Dictionary Methods

Create a dictionary of five students.

Practice:

- `get()`
- `keys()`
- `values()`
- `items()`
- `update()`
- `pop()`

---

## Loop Practice

Iterate through the dictionary and print:

```
Key : Value
```

Example:

```
name : Aman
age : 21
branch : CSE
```

---

## Challenge

Create a dictionary to store student details.

Display:

- Student Name
- Branch
- College
- Marks

Update the marks and print the updated dictionary.
