# Practice Questions – Conditional Statements

## Beginner

1. Check whether a number is positive or negative.
2. Check whether a person is eligible to vote.
3. Check whether a number is even or odd.

---

## Intermediate

1. Find the largest of two numbers.
2. Find the largest of three numbers.
3. Check whether a year is a leap year.
4. Check whether a number is divisible by both 5 and 11.

---

## Grade Calculator

Write a program that prints:

- A → Marks ≥ 90
- B → Marks ≥ 75
- C → Marks ≥ 60
- D → Marks ≥ 40
- F → Marks < 40

---

## Nested if

Write a program to determine whether a person can drive.

Conditions:

- Age must be at least 18.
- The person must have a driving license.

---

## Challenge

Create a simple login system.

Store:

- Username
- Password

Check if the entered credentials are correct.

Display:

- Login Successful
- Invalid Username or Password
