# Practice Questions – Break, Continue and Pass

## 🛑 Break

1. Print numbers from 1 to 10 but stop the loop when the number reaches 6.

2. Search for a number in a list and stop the loop when the number is found.

Example:

```python
numbers = [10, 20, 30, 40, 50]
```

Search for `30`.

---

## ⏭️ Continue

1. Print numbers from 1 to 10 but skip number 5.

2. Print only odd numbers from 1 to 20 using `continue`.

3. Create a list of numbers and skip all negative numbers.

---

## ⏸️ Pass

1. Create an empty function using `pass`.

2. Create an empty class using `pass`.

3. Create a loop where `pass` is used for a specific condition.

---

## ⭐ Challenge

Create a program that checks numbers from 1 to 20.

Rules:

- If the number is `10`, stop the loop.
- If the number is even, skip it.
- Print the remaining numbers.

Expected output:

```text
1
3
5
7
9
```
